Datenschutzhinweise

Der Rechner benötigt kein Benutzerkonto und speichert keine Berechnungen in einer eigenen Datenbank.

Technische Bereitstellung

Die Website wird über GitHub Pages ausgeliefert. Beim Abruf entstehen technisch notwendige Serverprotokolle beim Hostinganbieter.

Externe Kartendienste

Für Karte, Geocodierung und Routing werden Inhalte beziehungsweise Anfragen an OpenStreetMap, Nominatim, Valhalla und Overpass übertragen. Dabei wird technisch auch die IP-Adresse an diese Dienste übermittelt. Teile keine Ergebnis-URL, wenn Start oder Ziel vertrauliche Ortsangaben enthalten.

Lokale Verarbeitung

Die Berechnung und Darstellung erfolgen im Browser. Es sind derzeit keine eigenen Werbe-, Tracking- oder Analyse-Skripte eingebunden.
